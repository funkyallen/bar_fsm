# Aggregate results

- `table2_workflows.csv` contains the exact values used in Table 4(b) of the v5.7 manuscript (original reproduction filename `table1.csv`).
- `formal_686_audit.csv` contains the per-policy independent audit counts across the 686 locally cleared writes and 15/15 restart restorations (Table 4(a)).
- `accounting_baselines.csv` contains the 52-candidate accounting bound comparison across B0, B1, aggregate capacity, max(count, aggregate), B2, and the per-invoice capacity certificate (Table 5).
- `family_effects.csv` contains the family-level completion contrasts from Appendix A.

The CSVs come from the authors' frozen v5.7 study archive (`BAR-FSM-reproduction-v5.7.zip`). Raw episode and request records are supplied with that archive.
